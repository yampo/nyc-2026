# NYC 2026

Planificador del viaje a Nueva York (29 ago - 6 sep 2026). Es una sola pagina HTML,
sin build ni dependencias que instalar: `index.html` se abre y funciona.

## Sitio

Publicado con GitHub Pages: Settings -> Pages -> Deploy from a branch -> `main` / `/ (root)`.

## Como actualizarlo

Add file -> Upload files -> arrastrar el `index.html` nuevo (mismo nombre) -> Commit changes.
GitHub lo reemplaza y el sitio se actualiza en 1-2 minutos.

Los cambios que hacen Juan y Thais (tildes, notas, intereses, imprescindibles) se guardan
en el navegador de cada uno, no en el archivo: actualizar `index.html` no los borra.
